# Рубрики оценки

## Шкала

- 0 - отсутствует или противоречит AJTBD.
- 1 - есть попытка, но работа смешана с фичей, проблемой, персоной или догадкой.
- 2 - рабочий базовый уровень для курса.
- 3 - сильный учебный уровень: можно использовать как основу следующего интервью или проектного решения.

## Base Track: минимум прохождения

Base Track считается пройденным, если студент:

- сделал базовые домашки по своему проекту;
- нашел респондента или честно показал попытку поиска;
- провел 1-2 интервью или, если рекрут сорвался, явно пометил role-play/учебную транскрипцию как fallback;
- сдал `AJTBD Lens Card`.

| Критерий | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| Переключение оптики | Остался на фиче/проблеме/персоне | Работа названа, но формально | Есть работа через `человек хочет...` | Видно, как исходная фича/проблема переведена в работу |
| Ожидаемый результат | Нет результата | Результат абстрактный | Есть глагол и результат | Результат связан с конкретной ситуацией клиента |
| Критерии успеха | Нет критериев | "быстро/удобно/качественно" без уточнения | Есть 2-3 конкретных критерия | Есть критерии с границей "норма/проблема/ценность" |
| Элементы работы | Почти не заполнены | Заполнены случайно или догадками | Есть контекст, триггер, эмоции, результат, критерии | Ясно, что взято из данных, а что пока unknown |
| Работа -> решение -> проблема | Нет связки | Есть только проблема | Есть работа, решение и проблема | Проблема привязана к провалу решения против критериев |
| Активирующее знание и страхи | Нет | Общие слова | Есть 1-2 plausible пункта | Понятно, что человек должен узнать/чего боится/что удерживает в старом решении |
| Поиск респондента | Нет попытки | Респондент выбран случайно | Есть подходящий респондент или понятная попытка поиска | Понятно, какой прошлый опыт делает человека релевантным |
| Интервью / fallback | Нет разговора и нет fallback | Есть разговор без структуры или fallback без пометки | Есть реальный разговор или честно помеченный fallback | Реальный разговор дал материал для обновления Lens Card |
| Evidence / assumptions | Все смешано | Цитаты выданы как доказательство Job | Сырой материал, интерпретации и assumptions разделены | Для assumptions есть следующий вопрос или поведенческий факт для проверки |

## Base Track: interview guide

| Критерий | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| Рамка разговора | Нет рамки | Рамка раскрывает желательную гипотезу | Широкая нейтральная рамка | Рамка создает безопасность и не подсказывает ответ |
| Эмоциональный контакт | Не предусмотрен | Формальное "спасибо за участие" | Есть право не отвечать, запись/заметки, эмоции | Есть понятная человеческая формулировка начала разговора |
| Past behavior | Вопросы про будущее | Вопросы смешивают прошлое и "купили бы" | Большинство вопросов про прошлый опыт | Все ключевые вопросы anchored in past expenditure |
| Вопросы по работе | Вопросы про фичи | Вопросы только про проблему | Есть результат, решение, критерии, альтернативы | Вопросы помогают восстановить структуру работы |
| Уточнение абстракций | Нет | "Почему?" без конкретики | Есть уточнения "быстро/удобно/дорого" | Уточнения доводят до критериев и последствий |

## Field Track: AJTBD Learning Report

| Критерий | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| Серия интервью | Нет интервью | 1-2 разговора без структуры | 3+ разговора с заметками | 3-5 разговоров дают сравнимый материал |
| Изменение исходной картины | Не описано | "все подтвердилось" без доказательств | Есть, что подтвердилось/изменилось | Видно, как интервью изменили взгляд на проект |
| Работы между респондентами | Нет сравнения | Просто список разных ответов | Есть повторяющиеся работы/критерии | Видно, где одинаковые слова скрывают разные критерии |
| Решения и проблемы | Нет | Проблемы без решений | Есть текущие решения и проблемы | Проблемы связаны с критериями работы |
| Обязательная AJTBD-сегментация по работам | Нет | Группы по демографии/ролям без связи с Jobs | Группы собраны по похожим Core Jobs и критериям | Видно, какой сегмент с какой Core Job стоит проверять дальше |
| Сегмент / не сегмент | Нет проверки | Любая группа названа сегментом | Есть проверка через работу, критерии и past behavior | Видно, почему за этот сегмент есть или нет смысл конкурировать |
| ABCD/ABCDX, если применимо | Нет и не объяснено почему | Использован как ярлыки без данных | Есть упрощенный срез или честное "нельзя применить" | Понятно, как satisfaction/margin/proxy влияет на выбор фокуса |
| Sean Ellis, если применимо | Нет и не объяснено почему | Использован как единственная сегментация | Есть результат или честное "нельзя применить" | Понятно, что это слой удовлетворенности, а не замена AJTBD |
| Граф работ | Нет | Список шагов без уровней | Есть Big/Core/Micro/Small | Уровни связаны с данными из интервью |
| Сырой материал / assumptions | Все смешано | Частично разделено | Сырой материал, интерпретации и assumptions разделены | Для assumptions есть следующие вопросы или поведенческие факты для проверки |
| Рискованный следующий шаг | Нет | Общий список "что проверить" | Названа рискованная гипотеза | Назван дешевый способ ее опровергнуть |
| Финальный вывод | Нет | "надо делать продукт для всех" | Есть сегмент + работа + почему | Вывод следует из интервью, сегментации, графа работ и рискованной гипотезы |

## Advanced: Work Level Check

| Критерий | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| Проверка полноты | Нет | "продукт делает это" без доказательства | Есть проверка "выполняет полностью?" | Уровень работы обоснован через границы продукта |
| Big/Core/Micro | Смешаны | Термины названы, но путаются | В целом различены | Видно, почему работа Big/Core/Micro |
| Micro Jobs | Нет | Микрошаги выданы за ценность | Micro Jobs отделены | Понятно, какие микрошаги не стоит обещать как главную ценность |
| Small Jobs | Нет | Смешаны с Micro Jobs | Есть соседние работы | Видно, что рядом может быть территорией роста |

## Advanced: B2B Deal Lens

| Критерий | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| Роли сделки | Нет | Назван только пользователь | Есть ЛПР/пользователь/бюджет | Карта ролей включает влияющих и блокирующих |
| Бизнес и личные работы | Нет | Только KPI | Есть личные мотивы ролей | Личные работы связаны с риском, статусом, безопасностью |
| Покупочный процесс | Нет | "компания купит" | Есть этапы согласования | Видны бюджет, документы, задержки, критерии согласования |
| Вопросы интервью | Generic B2B вопросы | Вопросы про продукт | Есть вопросы про работу и покупку | Вопросы проверяют и работу, и возможность сделки |
