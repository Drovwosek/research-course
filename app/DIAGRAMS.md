# Иллюстрации в слайдах

В курсе используются оригинальные страницы PDF и кадры из лекций Ивана Замесина. Самодельные SVG-схемы удалены.

Подключение: отдельная строка Markdown `![Автор, лекция, страница или время](/app/assets/zamesin/имя.png)`.

Рядом с PNG обязательно сохранить одноимённый WebP без потерь: плеер использует его. Происхождение изображения записывается в `assets/zamesin/README.md`, пояснение — в заметках соответствующего слайда.

Не подменять схожим по виду изображением смысл слайда. Авторские упражнения нашего курса без прямого соответствия в источнике оформлять текстом. Стили оригинальных изображений находятся в `diagrams.css`.
